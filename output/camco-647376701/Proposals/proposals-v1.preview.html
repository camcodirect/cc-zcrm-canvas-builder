What the header does

  • Mail Merge (primary, generates the proposal document), Edit, More (clone, delete, share, print, and any custom buttons added later), right-aligned. All three are actions Zoho itself placed on this module's canvas, so they are known to exist for Proposals.
  • Proposals Name on the left, Proposal Status as a pill beside the buttons. Company, Prepared For, Email To, Related Account and Related Contact live in the Proposal Details card instead of the header.
  • Five glass tiles: Est. Total Cost, Billing Method, Payment Terms, Proposal Sent Date, Acceptance Date.

Tabs

  • Overview — details, billing, signature and invoicing keys, description, controls, special terms, tags, open tasks and meetings.
  • Pricing — one card per billing method (Hourly, Hour Blocks, Retainer, Fixed) plus the four cost KPIs.
  • Activity — Chronological View, Closed Tasks, Closed Meetings.
  • Record — system information, ownership and sharing, currency, Locking Information.
  • Related Account — Zoho's lookup All-Fields tab on the Related Account lookup: every field of the linked Account, grouped by the Accounts layout sections, live.
  • Timeline on its own tab, then one tab per remaining related list: Notes, Attachments, Emails, Checklists, Cadences.

Left off, on purpose

  • ChronologicalView History (near-duplicate of Chronological View), Unsubscribed Mode / Unsubscribed Time (email-opt-out plumbing), the empty Scope Items section. Corners are 3px or less throughout; shadows do the softening.
  • Blueprint and Stage components: valid on this module but their JSON has never been captured, so they are not emitted. Add them in the editor after deploy if wanted.
  • An All Fields tab: the editor generates one per module in one click; the one on file is Contacts-shaped and would be wrong here.
  • Toggle switches: not a Canvas element. Boolean fields render as Zoho's checkbox, shown above as it will look. The editor's Custom CSS box exists (every node has a custom_style slot) but no capture has ever shown it populated, so nothing is emitted there.
